# 材料考古

适用于朋友圈、微博、X、公众号、短视频文案、日记、聊天记录或其他历史内容。

## 先划研究边界

记录材料类型、起止时间、数量和明显缺口。区分：

- 当时直接留下的行为与语言；
- 后来在公开内容中回述的过去；
- 为了经营账号而主动选择的公开形象。

公开账号不是完整人生。材料只能支持“在这个时间范围和公开场景中观察到什么”，不能自动证明更早或更私人的人格。

## 提取单位

不要先按抽象主题做词频。优先提取能构成事件或反应的片段：

- 发生了什么；
- 当事人做了什么；
- 使用了什么有辨识度的原话；
- 选择与常规路径有何不同；
- 付出了什么成本；
- 得到了什么反馈；
- 原文位置、日期或文件名。

把“我很努力”“我喜欢学习”记作自我评价，不与行为证据混在一起。

## 聚类方式

按“面对同类刺激时如何反应”聚类，而不是只按话题聚类。例如，数码、健身和创业可能是三个话题，却共同表现“发现新工具后立刻亲测”；反过来，同一个创业话题里也可能出现多种人物机制。

重点比较：

- 同一反应是否跨年份、跨场景重复；
- 同一个东西进入不同人手里时，反应有何差异；
- 用户说自己是什么，与实际做法是否一致；
- 成功和失败后是否使用同一套解释方式；
- 哪些事件无法被当前模型解释。

## 形成结论

每条人物结论至少保留：支持事件、反例或边界、证据置信度。可以使用“已证实模式 / 较强假设 / 弱线索”区分成熟度。

不以形容词数量衡量完成度。一个能解释五个事件、预测未来反应的机制，优于十个宽泛标签。

材料量大、跨多个文件或跨一年以上时，必须先执行 [大规模材料处理协议](large-material-protocol.md)：分批建立事件索引、记录覆盖范围和缺口，再做跨批次归纳；不要仅凭最早读到或最戏剧化的一小部分下结论。
