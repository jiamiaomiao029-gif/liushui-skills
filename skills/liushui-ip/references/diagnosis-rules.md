# 两轴分流与诊断规则

## 目的优先

G1 表达/成长：用户是否有想表达的东西？是否负担得起持续输出？可不以成交为目标。避免为了流量剥夺个人表达的意义。

G2 职业影响力：受众主要是潜在雇主、同行、合作方。作品质量、问题解决过程、专业辨识度通常比泛流量更直接；注意保密与任职协议。

G3 商业获客：从目标客户当前任务和可提供的产品价值倒推内容承诺；有产品/交付能力/合法合规边界才讨论成交。内容流量高不等于客户意向高。

## 阶段优先

**S0 未稳定发**：过去案例和能力先行；没有专家履历时可采用「实践者/记录者/方法拆解者」的诚实定位。测内容生产成本和用户共鸣。

**S1 初期探索**：挑三个最有证据的内容切片，分辨哪些人在互动、问什么；比较相似作品，避免单条随机波动决定人生方向。

**S2 已运营**：看最后一段可量化的漏斗。若播放好但关注差，检查用户是否记住了「这个人下次还会提供什么」；若关注好但咨询差，检查目标客群、购买场景、服务承诺；若咨询好但成交差，检查资格、价格、信任证据或交付体验。每个环节都是可证伪的假设，不能一眼断因。

## 五个诊断问题

1. 能力：什么事你真实做过，能展示过程与限制？
2. 需求：谁在什么时候主动问过这个问题？还有哪些潜在替代解决方案？
3. 差异：竞争选项很多时，为什么用户在这个细分问题上会选择你？
4. 持续：不依赖传奇经历，6周内你还能持续给出哪些新案例？
5. 资源：可投入时间、设备、可公开身份、预算和必要技能是否足够？

## 诊断优先级

A. 可能误导用户的虚假背书或无法兑现的承诺 → 立即纠正。
B. 用户目标与定位价值不一致 → 先重新定位目标。
C. 缺少真实受众任务 → 优先验证需求，而不是润色slogan。
D. 用户需求明确但证据不足 → 先打造可展示的交付/作品。
E. 需求和证据齐备但传播不清 → 改进表达和识别符号。
F. 上述均可行 → 进入有指标的内容测试。
