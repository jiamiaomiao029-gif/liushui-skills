# 证据协议与研究边界

## 1. 最小证据表

| 声明 | 原始依据/日期 | 类型 | 支持什么 | 不支持什么 | 公开权限 |
|---|---|---|---|---|---|
| 「我会视频制作」 | 具体作品、链接、自己的参与范围 | 行为证据 | 曾交付作品 | 不自动证明稳定获客 | 用户确认 |
| 「网友想买课」 | 一条评论 | 弱需求信号 | 此人表达兴趣 | 不代表真实支付或普遍需求 | 匿名化 |
| 「某视频涨粉」 | 后台时间段、分母、归因 | 结果证据 | 一次增长 | 不代表全部内容和产品有效 | 用户决定 |

## 2. 来源分级（不是统计学置信区间）

- **直接证据**：能展示作品/原始过程/履约记录/用户提供的后台数据。注意口径及日期。
- **当事人确认**：用户清晰自述或亲历，尚无外部核验，可用于描述但注明口述。
- **旁人反馈**：评论、评价、访谈记录；应确认样本来源是否偏倚。
- **专家/培训经验**：可启发候选假设，不是市场规则或实证证明。
- **模型推测**：只作为待测试命题，显式标注。

不因相似观点在多个二次整理文档中重复出现，就自动提升证据等级。

## 3. 数据口径

分层记录：展现/播放 → 完播或停留 → 主页访问 → 关注 → 私信/咨询 → 合格线索 → 付费 → 交付 → 复购。每一层只在有原始分母和明确时间窗口时才计算转化率。

数字要标清：一条作品还是账号总量，付费意向还是实付，个人交付还是协作，发布后哪几天，样本量多少。

## 4. 高风险错误

- 单次爆款 → 保证可复制；
- 「咨询10人」→「成交10单」；
- 「客户买单」→「客户取得成果」；
- 目标人群是「年轻人」→ 自动认定愿付费；
- 粉丝数大 → 商业化成熟；
- 高价值课程内容 → 用户必然愿付费。

## 5. 私人材料

用户可以授权分析日记、朋友圈、咨询记录，但分析权不等于公开权。公开版本不得直接贴出具体客户姓名、年龄+城市+经历的可识别组合、交易流水、私人关系、医疗经历。未经用户明确选择，私人细节只能用于发现**可抽象的方法**。
