# 人物—定位输入简报（导入契约）

当 `liushui-ip` 接收人设考古结果时，只接收下列脱敏简报，不接收完整日记、聊天原文或第三方隐私。简报应与 `liushui-persona` 的输出格式一致。

```markdown
# 人物—定位输入简报

## 研究边界
- 已分析材料与时间范围：
- 覆盖缺口：
- 可公开边界：

## 已证实的行为模式
### 模式 1：
- 支持事件：
- 反例/成立边界：
- 证据成熟度：已证实模式／较强假设／弱线索
- 可用于：内容角度／能力证据／信任素材
- 不可推出：

## 可展示的能力或信任证据
- 可展示的作品、过程或结果：
- 当事人承担的真实角色：
- 不能作为专业背书的部分：

## 可转为内容的事件素材
| 事件 | 可讲角度 | 所证明的反应/机制 | 脱敏方式 | 不宜公开部分 |
|---|---|---|---|---|
|  |  |  |  |  |

## 与市场相关但尚未验证的假设
- 可能吸引的人群/问题：
- 仍缺少的需求、付费或交付证据：

## 明确不能推出的结论
- 人物特质不等于市场需求；
- 一次成就不等于稳定交付能力；
- 真实故事不等于应公开的故事。
```

收到简报后，仍须单独验证受众任务、需求证据、可兑现价值与资源可行性。
