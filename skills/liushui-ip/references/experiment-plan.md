# 最小14天验证计划

不是保证流量的「标准黄金配比」。对时间少的用户缩小样本，记录不足以比较的限制。

## 第0天：固定要验证的假设

例如：「对刚入职场、想从执行转向独立负责项目的人来说，拆解一个真实项目的决策过程，比泛泛职业鸡汤更能吸引有效反馈」。

标清目标G1/G2/G3、平台、时间投入和记录方式；不先写出期望涨粉数。

## 第1-3天：素材与访谈

列出两个候选方向；各找3个真实受众问题（来自用户授权材料、公开评论、访谈）。没有时明确标成模型猜测，优先私下访谈。每个方向各准备可展示证据，不能靠空口“我的经历特别强”。

## 第4-10天：最小样本

资源允许时，各方向发布2-3个可比内容/做小范围展示；资源不足时每方向1个作品+3次访谈，但只能得到弱信号。尽量控制形式、时长、发布时间等，不要求伪科学的绝对控制。

每条作品写：目标用户/一个问题/一个具体结论/一个证据/行动邀请。商业号的邀请应准确说明服务范围，而非虚构稀缺。

## 第11-14天：复盘与决策

记录每条的发布日期、曝光/播放、有效互动、关注、私信、访谈、合格线索等（仅记录平台提供的指标）。对G1观察「能否持续投入、评论是否理解表达」；G2观察「是否获得专业人士具体反馈」；G3观察「是否产生符合服务条件的咨询、为何没有」。

- 维持：目标受众理解且有重复的相关反馈，生产成本可承受。
- 修改：评论理解错承诺、只有泛泛流量或持续制作负担太高。
- 暂停：明显违规/虚假背书/隐私风险，或试验本身超出资源。
- 证据不足：如仅1-2条作品、观看极少，则不宣布赛道失败，延长验证或修改获取反馈渠道。

**一次主要迭代一个假设**：受众、承诺、形式、可信证据、渠道，不要同时全部更换，导致无法解释结果。
