# 发布前实验卡

发布前不预测“会不会爆”，只固定本轮要获得什么证据。

```markdown
# 内容实验卡｜[标题或内部编号]

## 本轮任务
- 主任务：触达／被理解／建立信任／获得行动信号
- 次任务（可选）：
- 目标对象与具体场景：
- 用户当前已知原话或行为：

## 内容假设
- 这条内容要让对象改变或确认什么理解：
- 核心承诺：
- 可展示证据：真实经历／作品／数据／引用／无
- 最大不确定性：

## 设计与可比条件
- 本轮主要变量：目标对象／问题承诺／开头或封面／证据／结构／行动入口／渠道
- 保持不变的条件：
- 无法控制的条件：发布时间、平台分发、热点等

## 观察计划
- 发布平台与统计窗口：
- 与主任务匹配的信号：
- 何种结果支持假设：
- 何种结果削弱假设：
- 数据不足时的处理：不下结论，补样本或换反馈渠道

## 发布后必记
- 实际文案/脚本版本：
- 数据口径：
- 用户原话：
- 意外信号：
```

一条内容可以有多个收获，但实验只设一个主问题。不要把“涨粉、卖货、建立人设、测试选题、练镜头”同时写成同一轮成功标准。
