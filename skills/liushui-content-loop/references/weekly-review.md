# 周度内容复盘

周复盘的目的不是挑“最好的一条”，而是让下一周只验证一个更清楚的问题。

```markdown
# 内容周复盘｜[日期范围]

## 本周研究边界
- 平台与内容数量：
- 每条数据统计截止时间：
- 本周原定主目标：
- 不可比较项：

## 内容实验总览
| 内容 | 主任务 | 主要变量 | 已观察信号 | 用户原话 | 当前结论等级 |
|---|---|---|---|---|---|
| | | | | | 事实／假设／未知 |

## 重复信号
- 支持较强的模式：
- 反例或冲突信号：
- 尚不能判断的部分：

## 下周只验证一个问题
- 问题：
- 假设：
- 实验样本：
- 只改的变量：
- 保持不变的条件：
- 观察信号与截止时间：
- 成立 / 推翻条件：
```

除非数据口径和任务可比，不将不同平台、不同内容目的或不同统计窗口硬排成排行榜。
