# 单条内容复盘

适用于用户已有一条内容、数据和部分反馈。先复原事实，再解释，最后只设计一个下一轮实验。

```markdown
# 内容复盘｜[标题或链接]

## 研究边界
- 平台与发布时间：
- 数据统计窗口：
- 内容版本：
- 可比较对照：
- 缺少的数据：

## 本轮原定任务
- 主任务：
- 目标对象与场景：
- 原定假设：

## 已观察事实
| 链条位置 | 指标或原话 | 口径 / 分母 / 时间窗 | 可支持什么 | 不支持什么 |
|---|---|---|---|---|
| 被展示 | | | | |
| 被点击或开始观看 | | | | |
| 持续观看 | | | | |
| 被准确理解 | | | | |
| 产生预期行动 | | | | |

## 当前判断
- 最早有证据的断点：
- 合理假设：
- 仍然未知：
- 不可得出的结论：

## 下一轮最小实验
- 只改：
- 保持不变：
- 新版本要验证的假设：
- 观察窗口与信号：
- 什么结果会推翻当前判断：
```

如果只有播放量或单个互动数字，只能报告“证据不足”，不得虚构留存、理解、转化或算法原因。
