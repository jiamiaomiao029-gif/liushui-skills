# 评论、私信与访谈信号协议

用户原话是需求线索，不是自动成立的市场结论。提取时保留语境和频次，避免把一句情绪化表达翻译成宏大人群画像。

## 脱敏规则

- 删除姓名、账号、联系方式、精确地点、单位和可识别经历组合；
- 不保存完整聊天记录，只保留支撑判断的最短必要摘录；
- 区分公开评论、私信、访谈和客户交付记录；分析授权不等于公开授权；
- 涉及医疗、家庭关系、财务、未成年人或敏感身份时，默认只保留抽象机制或不收录。

## 信号卡

```markdown
## 信号卡｜[日期 / 来源类型 / 匿名编号]

- 来源：公开评论／私信／访谈／咨询复盘
- 触发内容：
- 最短必要原话：
- 说话者处境（仅已明确部分）：
- 信号类型：问题／误解／反对意见／行动意向／结果反馈
- 支持什么：
- 不支持什么：
- 证据强度：单次弱信号／重复信号／已验证需求
- 可转化：下一条内容假设／访谈问题／产品验证问题
- 公开边界：可公开／需改写／仅内部
```

## 聚合规则

- 同一问题跨来源、跨时间重复出现，才可以升级为“重复信号”；
- 明确行动、付费或使用结果比“好有道理”“求更新”等泛反馈更强；
- 反对意见可暴露表达歧义或受众边界，不默认视为噪音；
- 不把用户称赞、朋友鼓励或单次咨询自动算作普遍需求；
- 汇总时输出“证据支持 / 反例或异议 / 仍缺验证”，再决定是否进入下一轮内容实验。
