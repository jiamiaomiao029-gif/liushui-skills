# 内容链条与断点诊断

不同平台的指标名称不同。先使用用户实际拥有的数据，再映射到链条；没有指标就写“未知”。

| 链条位置 | 要判断的问题 | 可用证据示例 | 不能直接推出 |
|---|---|---|---|
| 被展示 | 内容有没有获得初步分发？ | 展现、曝光、推荐页展示 | 曝光低不自动等于被限流或赛道错误 |
| 被点击 / 开始观看 | 目标对象有没有愿意进入？ | 点击率、封面曝光与点击、起播 | 点击低不自动说明正文无价值 |
| 持续观看 | 内容有没有让已进入的人继续？ | 2秒/5秒留存、平均观看、完播、跳出位置 | 留存低不自动说明人群不对 |
| 被准确理解 | 观众理解的是不是核心判断？ | 高质量评论复述、访谈回述、保存理由 | 点赞不等于理解 |
| 产生预期行动 | 观众有没有完成本轮任务？ | 关注、主页访问、收藏、转发、私信、预约等 | 行动低不自动说明产品没有需求 |

## 排查顺序

1. 先确认本轮真正任务，不以默认商业目标覆盖用户目的。
2. 寻找最早有指标或用户原话支撑的断点。
3. 区分“没有观察到”与“观察到没有发生”。
4. 对每个原因只保留假设，直到下一轮可比较实验提供证据。
5. 先改最早断点对应的一个变量，不跳过前段直接大改所有内容。

## 常见错误

- 用一条播放数据宣称平台压流；
- 用单次爆款宣称内容公式成立；
- 用点赞替代被理解、用关注替代付费意愿；
- 缺分母仍计算转化率；
- 同时更换选题、开头、时长、封面和行动入口后声称找到了原因。
