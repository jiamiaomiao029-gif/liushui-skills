# 内容实验闭环

内容不是一次性评价题，而是连续实验。任务是回答：**这轮验证了什么，证据支持什么，下一轮只改什么。**

## 使用边界

- 用户在决定长期人群、价值主张或产品方向时，优先使用 `liushui-ip`；本 Skill 只验证一条或一组内容实验。
- 用户在挖掘人物经历、人设事件或历史材料时，优先使用 `liushui-persona`。
- 用户只要写标题、脚本、逐字稿或剪辑建议时，不把复盘流程强塞进去；先由对应内容工具处理。
- 不凭一次播放、单条评论或平台传闻判断“限流”“赛道不行”“观众不喜欢”。
- 不编造平台规则、转化率、用户心理或数据分母。
- 不从私信、评论或咨询记录推断敏感身份、医疗状况、亲密关系或未明说的心理动机。

## 先识别入口

先吸收用户已给的数据、文案、截图文字、评论或记录；最多追问 1–2 个会改变判断的缺口。进入以下一个模式：

1. **发布前实验卡**：用户有选题、脚本或待发内容，想知道该测什么。完整读取 [references/pre-publish-experiment-card.md](references/pre-publish-experiment-card.md)。
2. **单条内容复盘**：用户带来已发布内容及数据，想知道问题在哪里。完整读取 [references/post-publish-review.md](references/post-publish-review.md) 和 [references/funnel-diagnosis.md](references/funnel-diagnosis.md)。
3. **评论 / 私信 / 访谈信号提取**：用户带来用户原话，想找需求、误解或下一条内容。完整读取 [references/user-signal-protocol.md](references/user-signal-protocol.md)。
4. **周度复盘**：用户带来多条内容的记录，想确定下周实验。完整读取 [references/weekly-review.md](references/weekly-review.md)。

用户明确只要一个快速判断时，交付当前最关键结论、依据、最大不确定性和一个下一步；不要强制完整表格。

## 统一工作协议

### 1. 明确本轮任务

每条内容只指定一个主任务，必要时标出次任务：

- **触达**：让目标对象停下、开始观看或点击；
- **被理解**：让目标对象准确复述核心判断；
- **建立信任**：让目标对象看见可信证据、表达方式或持续价值；
- **获得行动信号**：让目标对象进入主页、收藏、评论、私信、预约或完成其他明确动作。

不把播放、关注、私信、付费混为同一个成功指标。目标是表达或职业作品集时，不默认要求商业线索。

### 2. 固定最小证据账本

对本轮所有结论区分：

| 类型 | 含义 |
|---|---|
| 已观察事实 | 用户给出的文案、数据、原话、发布时间或可核验记录 |
| 合理假设 | 当前证据可解释但尚未证明的原因 |
| 未知 | 缺少分母、时间窗口、对照或关键数据，不能判断 |

所有数字标注平台、内容、统计时间窗和口径。没有分母不计算转化率；没有可比样本不写因果结论。

### 3. 诊断链条，而不是打总分

按可获得的数据检查：被展示 / 被点击或开始观看 / 持续观看 / 被准确理解 / 产生预期行动。平台没有对应指标时标记“未知”，不可用想象补齐。

先找**最早出现且有证据的断点**。后端行动弱，不自动说明开头差；播放弱，也不自动说明定位错。

### 4. 一次只改变一个主要变量

下一轮只能优先改一个：目标对象、问题承诺、开头/封面、证据、叙事结构、行动入口或分发渠道。其余关键条件尽量保持可比，并写明无法控制的变量。

## 输出

默认使用对应参考文件中的模板，并始终包含：

1. 本轮内容任务与目标对象；
2. 已观察事实、合理假设和未知；
3. 当前最早断点或证据不足位置；
4. 下一轮只改的变量、保持不变的变量与观察信号；
5. 当前结论可能被什么新证据推翻。

只有用户明确授权保存时，才将实验卡、复盘或信号整理写入本地文件。保存前确认目标路径，且只保留脱敏后的用户原话、汇总数据和必要链接；不保存完整私信、客户姓名、联系方式或敏感细节。

## 与其他 liushui Skill 协作

- 当连续实验显示目标对象、承诺或可兑现价值本身不清楚时，建议转入 `liushui-ip`，并只交接脱敏的实验摘要。
- 当评论和私信反复出现可验证的用户任务时，可将其作为 `liushui-ip` 的需求证据；单次原话只能作为弱信号。
- 当内容缺少真实事件、过程或人物反应时，可由 `liushui-persona` 提供已脱敏的事件素材；人物证据不自动等于需求证据。

## 结束前自检

- 是否把事实、假设和未知清楚分开？
- 是否用与当前任务匹配的信号，而非只看播放量？
- 是否避免从单条内容推出平台规律或长期方向？
- 是否只提出一个主要改动，而不是一份无法归因的大改稿？
- 是否保护了评论者、私信者和客户的隐私？
