# 方法边界与来源声明

本安装包提供的是一套可测试的工作流，不声称它是平台规律、心理诊断工具或确定性的商业预测模型。

## 方法性质

- 人设考古以用户授权的具体事件、行为记录和反例为依据，输出带成熟度与边界的人物假设；
- IP 定位把方向视为市场假设，要求区分能力证据、需求证据、信任证据和可持续供给；
- 14天计划用于收集可比较的反馈，不保证流量、涨粉、成交或收入。

## 材料与隐私

- 本安装包不包含第三方课程全文、书籍全文、真实客户记录或可识别的私人日记；
- 用户授权分析私人材料，不等于授权公开原文或可识别信息；
- 输出对外内容时，须处理第三方姓名、联系方式、精确地点、交易记录、医疗与关系隐私。

## 使用边界

- 培训、案例和创作者经验只能生成候选假设，不可写成平台官方规则或必然结果；
- 模型不能凭材料推断医疗诊断、敏感身份、未公开关系或他人隐私；
- 当证据不足、材料覆盖不完整或资源不可行时，应如实输出不确定性与下一步，而不是补造结论。

方法整合属于新的工作流设计；这不意味着对相关理论或经验主张的原创占有，也不转授任何第三方材料的版权。
